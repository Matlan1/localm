Video generation

        
Runs the Wan 2.2 workflow on your local ComfyUI (same VRAM
        handover as image generation). Keep the native 1280×704 resolution -
        the model was trained at 720p and quality collapses below it; iterate with
        short durations and fewer steps instead (~5 s is the native length). Video
        is the slowest generator: minutes to hours per clip.

Knowledge

        
Index folders or files into collections, then pick a collection in
        the chat parameters drawer - replies get grounded in the most relevant excerpts,
        with citations. Retrieval is BM25 (always works offline); embeddings are blended
        in automatically when the active model supports them. Collections live in the
        localm data directory under rag/.

Plugins

        
localm is a model loader plus a plugin engine. Only chat is active out of
        the box; install the others as you need them. Enabling or disabling a plugin takes effect
        instantly - no restart, no model reload.

        

          
First-party plugins

          

        

        

          
External plugins

          
A third-party plugin is a folder with a plugin.toml manifest
          under ~/.localm/plugins/; it can add a CLI command and export tools to the
          coder agent. Installation is a local directory copy.

          

            
            
          

          

        

      

    


    
    

      

        
Settings

        

          
Server configuration

          
Stored in ~/.localm/config.json. Engine values apply on

Performance

          
How much of the model runs on the GPU, and how large its context window
          is. Applies on the next model load. The VRAM figure is an estimate.
